# SLEDMC Website — Images & Media Needed

Please send the files below so we can replace the demo placeholders. High-resolution originals are best; we will optimise them for the web.
Only send photos of people who have agreed to appear on the website.

## 1. Brand
- **Logo:** vector file (SVG/AI/EPS) plus a transparent PNG, in a full-colour version and a white version for dark backgrounds.
- **Brand colours / guidelines:** if you have them. This includes the dark-theme colour reference image mentioned earlier.

## 2. Sector pathway videos (one per sector)
Short background clips: 10–20 seconds, landscape, 1080p MP4. No audio is needed.
- **Professional Drivers:** trucks on the road, a driver in the cab, training yard
- **Hospitality & Culinary:** hotel service, kitchen and chefs, housekeeping
- **Care & Healthcare Support:** caregivers with elderly people, a healthcare setting
- **Logistics & Warehousing:** warehouse aisles, fork-lifts, packing
- **Skilled Trades:** welding, electrical work, mechanics, construction

Please also send one still photo for each sector. It is shown while the video loads.

## 3. Sector brochures
- The final brochure for each sector, as a PDF plus a JPG/PNG of each page.
- Currently planned: Drivers 1, Hospitality 2, Logistics 1, Skilled Trades 1, Healthcare none yet.
