# Media checklist — drop files here, then ask to "rewire"

☑ = wired. Testimonial/story photos are auto-cropped to face-centred squares in `avatars/` sub-folders (originals untouched).

Each folder below also has a `README.md` with the same details.

**File formats**
- Photos can be `.jpg`, `.png` or `.webp`. Logos can also be `.svg`.
- Keep the base names shown below. The extension can be any of the formats above.
- Anything missing keeps its current placeholder.
