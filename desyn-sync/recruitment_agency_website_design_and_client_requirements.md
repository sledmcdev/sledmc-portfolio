# Recruitment Agency Website — Design & Client Requirements

## 1. Project Concept

The website is a recruitment agency website serving two primary audiences:

1. **Job Seekers / Candidates** — people looking for employment opportunities and career support.
2. **Organizations / Hiring Partners** — companies looking for talent and wishing to partner with the recruitment agency.

The website should maintain one consistent brand identity while providing **two distinct user journeys and experiences**.

# 6. Content/UX Separation

The two experiences should use the same brand but different priorities.

| Area | Job Seekers | Organizations |
|---|---|---|
| Primary Goal | Find a job | Find talent |
| Main CTA | Browse Jobs | Find Talent |
| Secondary CTA | Submit CV | Contact/Partner |
| Hero | Career-focused | Business-focused |
| Services | Candidate services | Recruitment services |
| Process | Candidate journey | Employer recruitment process |
| Testimonials | Candidates | Employers |
| Success Stories | Candidate stories | Recruitment case studies |
| Industries | Career fields | Industries served |
| Jobs | Very important | Low priority |
| Client Logos | Low priority | High priority |
| Awards | Medium | High |
| Career Advice | High | Low |
| Recruitment Expertise | Medium | High |
| Contact | CV/Application | Recruitment inquiry |

# 15. Core UX Principle

The website should not feel like one generic recruitment website with two buttons.

It should feel like:

```text
                    RECRUITMENT AGENCY
                           │
             ┌─────────────┴─────────────┐
             │                           │
        JOB SEEKERS                 ORGANIZATIONS
             │                           │
       "Find my next job"          "Find my next hire"
             │                           │
       Browse Jobs                  Find Talent
       Submit CV                    Partner With Us
       Career Support               Recruitment Services
       Candidate Stories            Case Studies
       Career Resources             Client Testimonials
             │                           │
             └─────────────┬─────────────┘
                           │
                    SHARED BRAND
              Trust • Expertise • Results
```

The **brand remains consistent**, but the **content hierarchy, messaging, CTAs, imagery and user journey should be different** for each audience.
