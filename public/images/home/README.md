# Home page

Any of .jpg / .jpeg / .png / .webp is fine (.svg also for logos). Keep the base name shown below;
if a file is missing, the site keeps showing its current placeholder.

| File | What to supply | Shown on |
|---|---|---|
| `hero.jpg` | Portrait 4:5, ~1200×1500 — team / candidates / recruitment executive | Home hero, right-hand image |
| `company-intro.jpg` | Landscape ~6:5, ~1400×1150 — office or team photo | Home › Company intro |
| `founder.jpg` | Portrait 4:5, ~1200×1500 — founder, high resolution | Home › Founder's vision (large photo + small avatar) |
