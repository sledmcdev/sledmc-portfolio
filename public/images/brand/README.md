# Brand / logo

Any of .jpg / .jpeg / .png / .webp is fine (.svg also for logos). Keep the base name shown below;
if a file is missing, the site keeps showing its current placeholder.

| File | What to supply | Shown on |
|---|---|---|
| `logo.png` | Main logo, square, transparent background, at least 512×512 | Header + footer (replaces /logo.png) |
| `logo.svg` | Optional vector version of the logo | Header + footer (preferred over PNG if supplied) |
| `logo-white.png` | Optional white logo for dark backgrounds | Dark theme header/footer |
